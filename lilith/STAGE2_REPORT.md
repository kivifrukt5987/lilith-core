## 2. Как запустить локально

```bat
:: демо без модели (стриминг, метрики, профили — всё настоящее, кроме модели)
python -m lilith_core.run --mock-brain

:: боевой режим с LM Studio / Ollama / llama.cpp:
::   1) поднять сервер модели (LM Studio: Developer → Start Server, порт 1234)
::   2) config.yaml: brain.profiles.chat.model: <имя модели из сервера>
::   3) config.yaml: features.brain_enabled: true
::   4) python -m lilith_core.run
```

В панели: селектор профиля в шапке (покажет `ok`/`offline`), ответ печатается
частичными кадрами, в мете — мс, ток/сек, токены, имя профиля.

## 5. Готовность к этапу 3 («Память»)

Контракты не сломаются: `InMemoryHistory.append/recent/clear` повторяет будущий
журнал; `agent_id` уже в контексте и в данных ответа — журнал и RAG ключуются им
с первого дня. Саммаризатор получит профиль `summarizer` из реестра.

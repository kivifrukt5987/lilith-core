# 🎙 Папки zero-shot-голосов

Каждый голос = папка `voices/<имя>/` с файлом `reference.wav`:

* 3–10 секунд чистой речи (без музыки, шума и вторых голосов);
* моно или стерео — движок обрежет сам, но моно надёжнее;
* чем ровнее и эмоциональнее прочитан референс, тем живее клон.

Дальше — запись в `config.yaml`:

```yaml
voice:
  profiles:
    clone:
      backend: zero-shot
      reference: voices/<имя>/reference.wav
```

и выбор профиля: `default_voice: clone` или `data.voice` в запросе озвучки.
Клон-движок (IndexTTS / XTTS / CosyVoice / F5) подключается в слот `zero-shot`
отдельным этапом — контракт уже зафиксирован в `voice/tts.py`.

Клонировать можно только голоса, на которые у тебя есть право и согласие владельца.

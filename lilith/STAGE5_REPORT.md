## 1. Что сделано

| Блок | Файлы | Суть |
|---|---|---|
| **Виземы (сервер)** | `face/visemes.py` | PCM-чанки TTS → окна 60 мс → RMS + zero-crossing → корзины **A/I/U/E/O/rest** + интенсивность 0..1. Серверная половина рта: тестируемо, переиспользуемо панелью, Unity и OBS |
| **Реестр персон** | `face/personas.py`, `personas/` | `personas/<id>/{persona.md, model.vrm, fallback.jpg, profile.yaml}`; горячий reload; `/api/personas` + статика `/personas/…`. Фундамент вкладок «Агенты» и «3D-модели» (этап 8). Твоя jpg-картинка уже живёт здесь как `lilith/fallback.jpg` |
| **VRM-вьювер** | `webui/vrm_viewer.js`, `webui/vendor/` | three.js + three-vrm + GLTFLoader **вендорены локально** (офлайн-требование панели): загрузка `model.vrm`, фолбэк-аватар, сглаживание визем (low-pass), idle: случайное моргание, дыхание, покачивание, **взгляд за курсором**, эмоции через blend-shapes |
| **Face-кадры по WS** | `app.py`, `protocol.py` | Типы `face`/`voice`: клиент шлёт `voice` → сервер стримит по тому же сокету аудио-чанки (base64 wav) + виземы с `offset_ms` + `done`; эмоции реплики уходят кадрами `face{kind:emotion}`. Один сокет на чат+лицо+голос |
| **Шина лица** | `face/bus.py` | Веер face-кадров внешним подписчикам: `/ws/unity` (зарезервированный адаптер Unity+VRM+SALSA) и будущая OBS-сцена этапа 8 |
| **Панель** | `webui/index.html` | Сцена над чатом (canvas + фолбэк-img), **face-debug оверлей** (режим/визема/интенсивность/эмоция/fps — критерии готовности проверяются без VRM), тумблер «🔊 озвучивать ответы», аудио-движок WebAudio с очередью и планировщиком визем |
| **Эмоции** | `face/emotions.py` (этап 5 v1) | Парсер тегов + алиасы словаря архитекторши (`smile→joy`, `angry→anger`, `sad→sadness`…), словари blend-shapes/просодии — остались сердцем |
| **VTuber Studio** | `face/vtuber_bridge.py` | Понижен до **опционального внешнего адаптера** (реконнект живой, тесты живые); Live2D-зависимостей не было и нет |
| **CLI** | `run.py` | `--with-face` для демо |

## 2. Критерии готовности (её словами) и как их проверить

| Критерий | Где смотреть |
|---|---|
| Панель открывается | `http://127.0.0.1:8765/` → сцена над чатом |
| Модель моргает и следит за курсором | положи `personas/lilith/model.vrm` → водим мышью по сцене; **без vrm** — фолбэк-img, а моргание/курс видны в debug-оверлее как значения |
| `[emotion: smile]` → улыбается | напиши реплику с тегом (или включи мозг и дождись тегов из persona.md) → blend `happy` + строка в оверлее |
| При озвучке рот движется по слогам | тумблер «🔊» → ответы озвучиваются, оверлей показывает смену визем A/I/U/E/O в такт |

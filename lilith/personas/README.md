# 👤 Персоны

Каждая папка = персона (будущая карточка агента):

```
personas/<id>/
├── persona.md     # душа: системный промт
├── model.vrm      # тело: VRM-модель (опционально; без неё — фолбэк)
├── fallback.jpg   # статичный аватар (png/jpg) — показывается, пока нет VRM
└── profile.yaml   # голос + brain-профиль персоны (и LoRA в будущем)
```

Панель берёт тело отсюда: `/personas/<id>/model.vrm`, список — `/api/personas`.
Новая папка = новая персона, без перезапуска (реестр перечитывается горячо).
